# Evaluation materials

Print the five-page PDF in `printable_boxes/` at actual size (100%) on A4 paper. Cut solid lines, fold dashed lines, and glue the tabs. Front panels retain the source label artwork; the back is marked TEST SAMPLE / NOT ACTUAL MEDICATION. This is reconstructed test packaging, not an original manufacturer carton template.

The original English package images and source URLs are in `package_images/`. Source: NLM DailyMed / American Health Packaging.

Use `demo_medications.json` as the reference list for the form. At 08:00 only Metoprolol Tartrate 50 mg is a match. Metoprolol Tartrate 100 mg is a wrong-strength distractor; Amlodipine Besylate 5 mg and Atorvastatin Calcium 40 mg belong to other schedules; Antacid / Calcium Carbonate 500 mg is not on the list.

For component checks, photograph each package separately. Make necessary fields unreadable to test Uncertain, then retake a clear photo. For participant evaluation, place all five boxes on the table, ask participants to locate and verify the 08:00 package, and complete simulated confirmation. No real medication is administered.
